## [0.1.0] - 2026-09-18

### Added

- Dependency-free, SSR-safe viewport and native safe-area controller.
- Conservative VisualViewport and VirtualKeyboard detection.
- CSS variables and optional utilities with pre-JavaScript fallbacks.
- Zero-config `auto` entry and local debug overlay.
- Astro, React, Vue, and Svelte adapters.
- Optional SSR-safe `<khm-safe-area>` custom element with pure and auto-registration entries.
- Unit tests, examples, package validation, and physical-device checklist.
- Real Chrome smoke tests for desktop/mobile rendering, console health, responsive overflow,
  custom-element updates, focus, and keyboard viewport state.
- Isolated tarball installation check for public exports and SSR behavior.
